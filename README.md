# atomic-orbitals-python
A simple Python script to visualize atomic orbital shapes. Designed as an educational/demo tool, it plots 3D orbitals with Matplotlib, shows nodal planes and positive/negative lobes, and can be easily modified to explore other orbitals or probability densities.


Usage
python plot_orbital.py
Or run in a Jupyter notebook for interactive exploration.
